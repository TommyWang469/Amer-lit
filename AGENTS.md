# American Literature workspace

## Before helping with a writing prompt

Read [writing/README.md](writing/README.md), then the three guides it lists. Apply these repository preferences without asking the user to repeat them. Read the actual prompt, supplied sources, rubric, and teacher feedback for the current assignment before drafting.

For a new essay, use the user's [initial work-and-leisure draft](assignments/work-and-leisure/notes/original-initial.txt) as the baseline voice sample. Later edited drafts include assistant wording and are not independent samples of the user's natural style. Newer user instructions and the actual assignment take priority over the saved defaults.

The standing priorities are a central argument, commentary that proves each topic sentence, the user's four-paragraph comparison structure, a conclusion connecting to the world and explaining why it matters, and natural language based on the user's own writing. The detailed guides explain the user's light grammar editing preference and the checks required before delivery. Aim for 90-level work without promising a teacher's grade.

## Organization

- Keep reusable writing guidance together in `writing/`; avoid duplicating its rules in assignment notes.
- Keep each assignment's sources, editable notes, and deliverables under `assignments/<assignment>/sources/`, `notes/`, and `final/`, `documents/`, or `presentations/`.
- Preserve source material and the user's original drafts. Remove confirmed duplicate or superseded outputs and temporary previews after checking retained copies and links.
- Keep temporary builds and renders in ignored directories; do not commit dependency links, font caches, or extracted copies of completed documents.
- When delivering a PDF, check text coverage and visually inspect the rendered pages. Link the final file directly.
