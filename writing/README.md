# Start here for future writing

These files contain the user's writing preferences and the lessons from their work-and-leisure essay. Read them before responding to a new writing prompt:

1. [WRITING_STYLE.md](WRITING_STYLE.md): voice, personal details, and light grammar editing.
2. [ESSAY_WRITING_GUIDE.md](ESSAY_WRITING_GUIDE.md): central argument, preferred structure, planning, and final review.
3. [LITERARY_COMMENTARY_GUIDE.md](LITERARY_COMMENTARY_GUIDE.md): researched rubric comparisons, developed commentary, examples, and an eight-question review.

Each guide owns a different part of the process. Keep voice rules in the style guide, essay organization in the essay guide, and detailed commentary methods and sources in the commentary guide.
